# Release selection

This folder is the proposed GitHub upload selection. It includes authors' recovered code, numeric evaluation artifacts, computational-label order, split hashes, configurations and permitted upstream MHAFR source with its original license. Numeric arrays include no SMILES or raw source rows. They support computational audit, not clinical interpretation.

Excluded from this folder: original notebooks with outputs, raw molecular tables, model checkpoints, private backups, V8 clinical evidence relations, MedDRA candidate identifiers/names, clinical concept mappings, review spreadsheets, external-source archives without an established redistribution license, and unrelated user files.

The 263 names are the model's original computational labels, not a claim of 263 MedDRA preferred terms. The numeric class-to-target map reproduces the training-derived lookup. V8 registry and terminology files remain separate; no statement of legal clearance is made. The authors must confirm applicable source terms before public publication and select a license for their own code. No upstream copyright/license notice has been removed.

Use this folder, not the earlier all-in-one preparation ZIP, as the proposed repository content. After publishing a tagged release, cite its real URL and commit in Comment 8. Full closure still depends on the explicit remaining items.
